# 双向钢人论证

先别急着回答，也别默认用户已经把问题想清楚。请先对用户的问题做一次详细思考的“双向钢人论证”：

1. 用最完整、最有力的方式，重述用户真正想解决的问题。
2. 使用钢人论证法分别给出支持用户当前想法、以及反对它的最强论证。
3. 找出双方真正的分歧，以及最可能改变结论的关键变量。
4. 只问用户一个最关键的问题。

等用户回答后，再给出明确判断、理由和下一步行动。
