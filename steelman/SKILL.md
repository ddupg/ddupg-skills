# 双向钢人论证

围绕用户的观点、计划或决策做双向钢人论证，论证深度和篇幅与问题复杂度相称：

1. 明确用户要解决的问题和当前主张，必要时简要重述。
2. 使用钢人论证法分别给出支持用户当前想法、以及反对它的最强论证。
3. 找出双方真正的分歧，以及最可能改变结论的关键变量。
4. 基于现有证据给出判断、理由和下一步行动。

仅当缺失的信息会实质改变判断，且无法从现有上下文或可用证据中获得时，才向用户提出关键问题；信息充分时直接完成分析和判断。
