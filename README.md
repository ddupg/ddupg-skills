# ddupg-skills

这里收集我自用的通用 skills，供不同 agent 在需要时读取和执行。

## Skills

| Skill | 用途 |
| --- | --- |
| `with-linear` | 按 Linear issue 推进工作，及时更新 issue 状态，并把重要信息、结论和验证结果记录回 issue。 |
| `next-issue` | 从当前工作区、Linear、GitHub 等上下文中找出接下来最值得处理的任务，并给出简短的优先级建议。 |
| `gauntlet` | 在远程 Linux 机器的独立用户环境中复现问题、验证改动或运行真实集成测试，保留隔离边界和可追溯证据，按需使用辅助脚本。 |
| `with-git` | 沉淀 git worktree 与 GitHub PR 发布收尾里的非默认最佳路径，包括 sibling worktree 与 GitHub 命令提权执行。 |
| `steelman` | 对观点、计划或决策做双向钢人论证，先厘清正反论据、分歧与关键变量，再给出判断。 |
| `visual-explanation` | 创建、评审或重绘架构图、调用链、流程图、机制解释图与其他技术可视化。 |
